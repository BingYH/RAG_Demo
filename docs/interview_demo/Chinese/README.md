## 要让观众看到的三个工程结论

1. 即使末段误差通过，两个瞬态响应要求仍不通过。最终到达目标位置并不足够。
2. Kd 从 0.85 变为 0.10，阻尼减弱是有依据的优先假设；仍需核查变更意图、测试条件，并进行受控复测。
3. 当前负载和惯量缺失时，不能用登记基准补齐。工作流会追问、保留未知，并允许带着明确缺口继续处理。

## 要让观众看到的三个软件设计决定

1. Python 负责数值、完整性检查和通过/失败判定；LLM 选择事实、解释证据；应用程序生成绑定后的数值和引用。
2. LangGraph 管理分支、一次澄清、有界检索和纠正及审批；LangSmith 让执行和复核结果可检查。
3. 只读证据采集与经批准的本地工单写入分开。人工批准绑定完整草稿的哈希，不等于批准设备运动。
