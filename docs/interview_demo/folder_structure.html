RAG_Demo / Project folder structure

100% Mermaid source
Scroll to explore. Ctrl + wheel to zoom. Drag blank space to pan. Click a folder to collapse it. F11 also toggles browser full screen.
  • RAG_Demo/
    • Project entry points
      • streamlit_app.py - bilingual Dashboard
      • README.md / AGENTS.md / RAG_DEMO_PLAN.md
      • requirements.txt / .streamlit/config.toml / .gitignore
    • rag_demo/ - AI application
      • workflow.py - LangGraph state and routing
      • diagnosis.py / review.py - generation and review
      • retrieval.py / facts.py - retrieval and source binding
      • dashboard.py / tickets.py / tracing.py / config.py / ui_i18n.py
    • knowledge/ - curated RAG documents
      • 00_overview/ / 10_configuration/ / 20_procedures/
      • 30_troubleshooting/ / 50_support/
      • 40_cases/ - reserved; archived/ - excluded from current index
    • simulator/ - synthetic evidence and read-only tools
      • motion.py / motion_tools.py / tools.py
      • ros_capture.py / http_motion.py
      • scenarios/ - initialization state.json and diagnostic.log
      • motion_scenarios/ - joint-response state.json and trajectory.csv
    • ros2/bench_replay/ - project-owned ROS 2 package
      • bench_replay/publisher.py / collector.py / runtime.py
      • package.xml / setup.py / setup.cfg / resource/
    • scripts/ - run, inspect, validate and prepare
      • graph_bench.py / diagnose_bench.py / smoke_trace.py
      • ros_replay_bridge.py / build_ros_replay.sh / run_ros_replay.sh
      • inspect_*.py / generate_motion_fixtures.py / validate_fixtures.py
      • evaluate_review.py / check_language.py / setup and verification scripts
      • prepare_interview_demo.py / render_interview_diagrams.py
    • docs/ - design, operation and provenance
      • Bench, motion, workflow, tickets, Dashboard and WSL/ROS guides
      • interview_demo/ - notes, run of show, Mermaid, SVG and PNG
      • sources.md / source_manifest.json / diagnosis_validation.md
    • tests/ - offline tests with fake models
    • evaluation/cases/ - review regression inputs, excluded from RAG
    • data/ - ignored local runtime artifacts
      • checkpoints/ / runs/ / tickets/ / ros_captures/
      • index/ / models/ / motion_reports/ / presentation/ / wsl_validation/
    • references/repos/ - ignored third-party clones; keep unchanged
      • docs / libfranka / libfranka-common / franka_ros2 / franka_description / labs
    • .venv/ - ignored local Python dependencies
